### 1.4 统一约定

**响应格式**

```ts
// 统一响应结构
interface ApiResponse<T = unknown> {
  code: number;       // 0 成功，非 0 失败
  message: string;
  data: T;
}
// 分页响应
interface PageResult<T> {
  list: T[];
  total: number;
  page: number;
  pageSize: number;
}
```

**鉴权**：登录后返回 `accessToken`（有效期 2h）+ `refreshToken`（7d）。前端 Axios 请求拦截器自动附加 `Authorization: Bearer <token>`；401 时用 refreshToken 静默刷新，失败则跳转登录。

**角色**：学生端所有接口需 `role: STUDENT` 中间件校验，禁止越权访问后台数据。

## 三、状态管理（Pinia）

### 3.1 user store

```ts
// stores/user.ts
export const useUserStore = defineStore('user', () => {
  const studentInfo = ref<StudentInfo | null>(null);
  const accessToken = ref<string>(localStorage.getItem('token') || '');
  const refreshToken = ref<string>(localStorage.getItem('refreshToken') || '');

  async function login(payload: LoginParams): Promise<void> { /* 调 api，存 token */ }
  async function fetchStudentInfo(): Promise<void> { /* 获取个人档案 */ }
  function logout(): void { /* 清空 state 与 localStorage */ }
  return { studentInfo, accessToken, refreshToken, login, fetchStudentInfo, logout };
}, { persist: { paths: ['accessToken', 'refreshToken'] } });
```

### 3.2 notice store

缓存未读公告数，供布局组件角标展示；`markRead(id)` 调接口后递减。

### 3.3 dict store

启动时拉取并缓存字典（学籍状态、请假类型、奖惩类型等），供下拉框复用，避免重复请求。

```prisma
  reviewerId  String?
  reviewedAt  DateTime?
  createdAt   DateTime @default(now())
}
```

**API 接口**

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/api/student/auth/login` | 学号 + 密码登录，返回双 Token |
| POST | `/api/student/auth/refresh` | 刷新 Token |
| POST | `/api/student/auth/logout` | 登出 |
| GET | `/api/student/profile` | 获取个人档案 |
| PUT | `/api/student/profile/info-edit` | 提交信息修改申请（敏感字段走审批） |
| PUT | `/api/student/profile/password` | 修改密码（需校验原密码） |
| POST | `/api/student/profile/avatar` | 上传头像（Multer） |

**前端实现任务**

1. `views/login/index.vue`：学号/密码表单，Element Plus `el-form` 校验，登录成功跳 `/profile`。
2. `views/profile/index.vue`：展示个人档案，敏感字段（联系方式、住址）旁带"申请修改"按钮。
3. `views/profile/edit.vue`：信息修改申请表单，提交后生成 `InfoEditApply` 记录，状态置 PENDING。
4. `views/profile/password.vue`（弹窗或子页）：修改密码。
5. `components/FileUploader.vue`：封装头像上传，限制 2MB、jpg/png，调用 `/profile/avatar`。
6. `composables/useAuth.ts`：封装登录态判断、token 刷新逻辑。

**后端实现任务**

1. `services/auth.service.ts`：bcrypt 校验密码、签发 JWT（payload 含 `studentId`、`role: STUDENT`）。
2. `services/profile.service.ts`：查询档案、创建修改申请、密码更新。
3. `middlewares/auth.ts` + `middlewares/role.ts`：解析 Token 并校验角色。
4. `routes/auth.routes.ts` + `routes/student.routes.ts`：挂载上述接口。
