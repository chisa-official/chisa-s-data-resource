### 1.4 统一约定

- 响应格式、JWT 双 Token、统一错误处理与学生端一致（见学生端任务书 1.4）。
- 后台接口统一前缀 `/api/admin/`，中间件强制校验非 STUDENT 角色。
- 接口级权限：每个接口关联一个 `permission` 标识（如 `student:create`），中间件校验当前角色是否拥有该权限。

## 二、权限模型与动态路由

### 2.1 RBAC 数据模型

```prisma
model Admin {
  id        String   @id @default(uuid())
  username  String   @unique
  password  String                  // bcrypt
  realName  String
  roleId    String
  role      Role     @relation(fields: [roleId], references: [id])
  phone     String?
  status    AdminStatus             // ACTIVE / DISABLED
  lastLoginAt DateTime?
  createdAt DateTime @default(now())
}

model Role {
  id          String   @id @default(uuid())
  name        String   @unique       // 超级管理员 / 学工老师 / 辅导员 / 教务员 / 宿管
  code        String   @unique
  dataScope   DataScope              // ALL / DEPARTMENT / SELF 数据权限范围
  menus       Json?                  // 可访问菜单 ID 数组
  permissions Json?                  // 接口权限标识数组
  admins      Admin[]
  createdAt   DateTime @default(now())
}

model Menu {
  id        String   @id @default(uuid())
  parentId  String?                  // 树形结构
  name      String                   // 菜单名称
  path      String?                  // 前端路由 path
  component String?                  // 前端组件路径
  icon      String?
  sort      Int      @default(0)
  type      MenuType                 // DIRECTORY / MENU / BUTTON
  permission String?                 // BUTTON 类型关联的权限标识
  visible   Boolean  @default(true)
  children  Menu[]
  createdAt DateTime @default(now())
}
```

预置角色：
- `SUPER_ADMIN`：全部权限
- `ACADEMIC_AFFAIRS`（教务员）：教务模块 + 基础数据 + 学籍
- `COUNSELOR`（辅导员）：学工（请假审批、奖惩）、考勤、本班学生查看
- `STUDENT_AFFAIRS`（学工老师）：学工全模块、宿舍、奖助贷
- `DORM_MANAGER`（宿管）：宿舍模块

### 2.2 动态路由实现

**后端**：`GET /api/admin/auth/menus` 返回当前角色可见菜单树。

**前端**：
1. 登录后 `stores/permission.ts` 调用接口获取菜单树。
2. 递归将菜单数据转为 `RouteRecordRaw`，`component` 字段映射到 `views/` 下组件（用 `import.meta.glob` 动态导入）。
3. `router.addRoute()` 动态注册，注册完成后 `next({ ...to, replace: true })`。
4. 侧边栏 `Sidebar.vue` 根据菜单树渲染 `el-menu`。

**按钮级权限**：`composables/usePermission.ts` 提供 `hasPermission('student:create')`，配合 `v-if` 控制按钮显隐。
